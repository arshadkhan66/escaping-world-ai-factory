# Escaping World AI Factory

## Mission
Build a zero-budget hybrid AI software factory that helps plan, write, test, and document software.

## Environment
- Device: Android phone.
- Internet: regular internet connection.
- Budget: zero. Do not spend money or use paid APIs or paid model credits.
- Repository: escaping-world-ai-factory on GitHub.

## Main goals
1. Keep project plans and progress in files saved in GitHub.
2. Automate coding and testing where free tools allow.
3. Use AI coding agents only when access and billing conditions are understood.
4. Investigate a local-model fallback if it works on the available hardware.
5. Recover work safely after interruptions or usage limits.

## Safety rules
- Never enable billing or buy credits without explicit approval.
- Never put passwords, API keys, or access tokens in project files.
- Make small changes and review them before merging.
- Never claim a test passed unless it was actually run and its result was observed.
- Document errors and limitations honestly.

## Initial roadmap
1. Create project memory and planning files.
2. Add a minimal Python test.
3. Configure automated tests with GitHub Actions, subject to free usage limits.
4. Verify the workflow from an Android phone.
5. Evaluate free AI coding options and local-model fallback without spending money.

## Completion rule
Record what changed, what was actually tested, what remains unfinished, and the exact next action.
